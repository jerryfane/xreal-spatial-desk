How placement works

Each screen is a flat (or curved) panel at a position on a sphere around your head, set by four numbers:

Yaw = how far left/right (°). Pitch = how far up/down (°). Distance = metres from your eyes. Size = diagonal in inches. The screen always faces you.

Every frame, the head angle from the glasses' motion sensor is subtracted, so screens stay put while you look around. Recenter moves the whole layout to wherever you are currently facing.

Distance vs size: with 3DoF, only the angle a screen covers matters. A 48″ screen at 1.5 m and a 96″ screen at 3 m look the same size, but stereo depth changes.

Sharpness: about 43 panel pixels per degree. A screen wider than about 42° doesn't fit in view at once, and its text is drawn with fewer panel pixels. See the readouts under Screens.

Native vs Mac: in native modes the Mac sends an ordinary flat desktop and the glasses move it (see “Cable signal”). In Mac mode the Mac draws both eye views itself, so every frame is a little late. Run the look-around demo to see the screens drift.
